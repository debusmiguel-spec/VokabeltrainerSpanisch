SPANISCH VOKABELTRAINER V2 – ANDROID/PWA

Diese App ist eine separate spanische Version des Englisch-Vokabeltrainers.

Empfehlung:
Erstelle für die spanische App ein eigenes GitHub-Repository, z. B.
spanisch-vokabeltrainer

GitHub Pages:
1. ZIP entpacken.
2. Dateien in das neue Repository hochladen:
   index.html
   manifest.webmanifest
   service-worker.js
   icon.svg
3. Settings -> Pages -> Deploy from a branch -> main -> /(root)
4. Die erzeugte HTTPS-Adresse auf Android in Chrome öffnen.
5. "App installieren" bzw. "Zum Startbildschirm hinzufügen" wählen.

Die Daten der spanischen Version werden getrennt von der englischen Version gespeichert.
